- `vanx-architecture.md` 升级 v2：新增 §2 三层目录（responsive/ 分发 + h5/ 与 pc/ 双实现 + ui/ 共用）、§4 契约扩至 11 条（含 data-mode、props 双模式一致性、forceMode 逃生舱）、§6 响应式双实现机制（三种落地模式 A/B/C、useDeviceMode 判定含 pointer 能力、SSR 默认 desktop 防 hydration mismatch、h5/pc 分模式 lazy 按需加载）、§8 任务卡增加双模式定义字段。

- 品牌与工程命名落地：包名与 CLI `bivane`、registry namespace `@bivane/<name>`、token 前缀由 `--vx-*` 改为 `--bv-*`、组件名不加前缀、slogan「一套 API，两端各得其所」。
- 文档更名完成：`vanx-architecture.md` → `bivane-architecture.md`（v3，新增 §1.1 品牌系统与 §1.2 工程约定）、`vanx-responsive-matrix.md` → `bivane-responsive-matrix.md`（v2）；旧命名文件已删除。
